# 🤖 LangChain AI Chatbot  

This is a simple **AI Chatbot** built with **LangChain** and **Gradio** using **Google Gemini API**.  
It was created as a learning project while exploring LangChain for conversational AI.  

---

## 🚀 Features  
- 🗣 Chat with an AI powered by **Google Gemini** via LangChain  
- 💬 Maintains conversation context using **SystemMessage, HumanMessage, and AIMessage**  
- 🔄 Simple start/stop functionality: type "exit" or click the **Exit Chat** button  
- 🌐 Web-based interface using **Gradio**  

---

## 🛠 Tech Stack  
- **Backend / AI:** Python, LangChain, Google Generative AI (Gemini)  
- **Frontend / UI:** Gradio  
- **Environment Management:** dotenv
